# Stroke Prediction: ML Model Application & Evaluation
Course: Introduction to Data Science

- **Dataset:** Stroke Prediction Dataset (Kaggle, fedesoriano): https://www.kaggle.com/datasets/fedesoriano/stroke-prediction-dataset
- **Problem:** Classification (stroke = Yes/No)
- **Models:** Logistic Regression, KNN, Decision Tree, Random Forest
- **Metrics:** Confusion Matrix, Accuracy, Precision, Recall, F1, ROC-AUC
- **Best model:** Logistic Regression (highest Recall, fewest missed stroke cases)
- **Notebook:** Stroke_Prediction_ML_Models.ipynb
